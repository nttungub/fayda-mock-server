🇪🇹 Fayda Mock eSignet — Console

Local test-only stand-in for the VeriFayda 2.0 / eSignet OIDC flow. No real identity data. All state lives in this server's memory and resets on restart.

What this is

This console gives you a clickable front end for the endpoints documented in README.md. It does not replace the OIDC endpoints themselves — it just calls them from the browser instead of curl.

EndpointPurpose
GET /.well-known/openid-configurationDiscovery document — open
GET /jwks.jsonThis server's public signing key — open
GET /authorizeLogin form (built by the server)
POST /oauth/v2/tokenCode → tokens
GET /oidc/userinfoSigned JWT of claims
/admin/clients, /admin/identitiesManage test data — see the tabs above

Suggested order

  1. Register a relying party in Clients (or let this console generate a throwaway signing key for you).
  2. Check or create a fake citizen in Identities.
  3. Run the whole authorize → token → userinfo flow end to end in Try the Flow.
